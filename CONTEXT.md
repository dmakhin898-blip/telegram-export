# Telegram digest

Еженедельный дайджест каналов из `channels.yaml`. Читатель отмечает темы и по этим отметкам видит, какие каналы ему полезны.

## Language

**Полезная отметка**:
Галка «Полезно» на полной теме в дайджесте.
_Avoid_: «Почитать в телеграмме», рекомендация, лайк, просмотр

**Канал**:
Запись в `channels.yaml`. Один и тот же канал, даже если заголовок `###` в разных дайджестах написан по-разному.
_Avoid_: текст заголовка `###`, короткое имя в тизере

**Счёт полезного**:
Сумма полезных отметок одного канала по всем дайджестам.
_Avoid_: полезные за текущую неделю, число тем в выпуске
